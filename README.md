# Bank-Loan-Report-Dashboard
The Bank Loan Report Dashboard is an Excel-based project inspired by a YouTube tutorial. It automates the analysis and visualization of a bank’s loan portfolio, providing critical insights into various loan metrics. This dashboard empowers decision-makers with real-time data and in-depth analysis.
# 🏦 Bank Loan Report Analysis (Excel Dashboard)

## 📌 Project Overview
An interactive Microsoft Excel dashboard designed to analyze bank loan performance, borrower demographics, and lending trends. This project tracks key financial KPIs—including loan applications, funded amounts, received amounts, interest rates, and debt-to-income (DTI) ratios—to help stakeholders evaluate portfolio health and risk.

## 🔍 Key Visualizations & Insights
* **Monthly Trends by Issue Date:** Area chart tracking application volume across the calendar year (Jan–Dec), highlighting peak lending periods in the second half of the year.
* **Regional Analysis by State:** Filled map displaying geographic distribution of loan applications across the U.S. (with major volume in states like CA, TX, NY, and FL).
* **Loan Term Analysis:** Donut chart comparing repayment periods, showing that **60-month loans (85%)** heavily outweigh **36-month loans (15%)** in the filtered view.
* **Loan Purpose Analysis:** Column chart breaking down borrower intent, led overwhelmingly by **Debt Consolidation** and **Credit Card** refinancing.
* **Home Ownership Analysis:** Treemap illustrating borrower housing status across **Rent (18,439)**, **Mortgage (17,198)**, and **Own (2,838)**.

## 🛠️ Excel Tools & Techniques Used
* **Pivot Tables & Pivot Charts:** Aggregated raw loan data across multiple dimensions (time, state, term, purpose, and home ownership).
* **Interactive Slicers:** Added dynamic filtering for **Loan Grade (A–G)**, **Verification Status** (Verified, Source Verified, Not Verified), and **Loan Status** (Good Loan vs. Bad Loan).
* **KPI Cards:** Linked dynamic summary metrics to pivot outputs for real-time updates when slicers are toggled.
* **Data Cleaning & Formatting:** Standardized date fields, currency formatting, and percentage calculations prior to modeling.

## 🚀 How to Use
1. Download the `.xlsx` file from this repository.
2. Open it in **Microsoft Excel** (Desktop version recommended for full map chart and slicer interactivity).
3. Use the slicers on the left panel to filter metrics by **Grade**, **Verification Status**, or **Good vs. Bad Loan**.
